Coding Standards
Naming
Screens: LoginScreen DashboardScreen

Variables: monthlyIncome totalExpense

Colors
Use theme.md colors only.

Files
One screen per file.

Commits
Small and meaningful commits only.

Examples:

Add login screen

Fix dashboard layout

Update expense module

Documentation
Every screen and module should be documented clearly.

Folder Structure
ui-design database docs mobile-app testing

Security
Do not store PINs in plain text. Use secure authentication methods.
